# Polybot Market Data
Public dataset of Polymarket binary options tick data for backtesting.

## Structure
- `sessions/ticks/` — Raw tick data per market
- `sessions/snapshots/` — Market snapshots
- `data/extracted/` — Normalized backtest-ready data
- `sessions/15m/metrics.jsonl` — 15m session metrics
- `sessions/1h/metrics.jsonl` — 1h session metrics
